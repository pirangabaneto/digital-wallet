# PirasWallet

PirasWallet é uma aplicação de carteira financeira desenvolvida em **Laravel 10**, utilizando **Blade** com **Tailwind CSS** para a interface. O sistema permite que usuários realizem transferências, depósitos e acompanhem o histórico de transações.

## 🚀 Tecnologias Utilizadas

- **Laravel 10** – Framework PHP 
- **Blade** – Template do Laravel  
- **Tailwind CSS** – Estilização da interface  
- **PHPUnit** – Testes automatizados  
- **Figma** – Prototipagem da versão web e mobile

## 📌 Funcionalidades

- Cadastro e autenticação de usuários
- Transferência e depósito de saldo
- Validação de saldo antes da transferência
- Reversão de operações
- Interface responsiva para web e mobile
